# India-Education--Dashboard-Power-BI
A Power BI portfolio project analysing school education data across all 36 states and UTs of India using real government data from the Unified District Information System for Education Plus (UDISE+).
# 📊 Dashboard Pages
Page 1 — National Overview

Total Schools, Students, Teachers and Pupil-Teacher Ratio (KPI Cards)
Enrolment by State (Bar Chart)
Pupil-Teacher Ratio by State (Bar Chart)
Interactive State Slicer

Page 2 — Infrastructure Analysis

Electricity, Drinking Water, Girls Toilet, Internet and Computer coverage % (KPI Cards)
Infrastructure comparison across states (Clustered Bar Chart)
Interactive State Slicer

Page 3 — State Overview

State-wise enrolment distribution (Treemap)
UP, Bihar and Maharashtra dominate enrolment volume

# Key Insights

UP, Bihar and Maharashtra account for nearly 40% of India's total school enrolment
Internet facility is available in only ~57% of schools — highlighting a significant digital divide
Girls Toilet coverage stands at ~92.5% nationally, though functional availability varies by state
Single-teacher schools remain a challenge in smaller states and UTs

Data is sourced from the Government of India under the National Data Sharing and Accessibility Policy (NDSAP) — open for public use.
